# Eco Glow Cleaning Solutions Website

## 1. Project Title

**Eco Glow Cleaning Solutions – WEDE5020 POE**

## 2. Project Overview

Eco Glow Cleaning Solutions is a website developed for an environmentally friendly cleaning business. The website provides information about the company, its cleaning services and its eco-friendly products.

The purpose of the website is to create an online presence for Eco Glow, allow customers to explore available services and products, and make it easier for customers to contact the business or submit enquiries.

This project was developed using HTML5, CSS3 and JavaScript in Visual Studio Code.

## 3. Company Background

Eco Glow Cleaning Solutions was established in 2022 by Naledi Khumalo in Johannesburg, South Africa. The company started with three employees and focuses on providing effective cleaning services while using environmentally friendly products.

The business provides home cleaning, office cleaning and deep cleaning services in Johannesburg and Pretoria, Gauteng.

### Mission

To provide safe, sustainable and effective cleaning services using environmentally friendly products.

### Vision

To become one of South Africa's leading eco-friendly cleaning brands, with plans to expand product sales and franchising by 2030.

## 4. Project Objectives

The main objectives of the website are to:

- Introduce Eco Glow Cleaning Solutions to potential customers.
- Provide information about the company's background and services.
- Display eco-friendly cleaning products.
- Allow customers to submit enquiries and contact the business.
- Improve the user experience through interactive website features.
- Make the website responsive on desktop, tablet and mobile devices.
- Improve the website's search engine optimisation (SEO).

The website contains the following pages:

| Page | Description |

## 8. Dynamic Product Functionality

The products page uses JavaScript to load product information from:

`data/products.json`

Customers can:

- View the available products.
- Search for products by name or description.
- Filter products by category.
- Sort products according to price.
- View product descriptions and prices.

This functionality makes the products page more interactive and user-friendly.

## 9. Forms and Validation

The website contains two different forms.

### Enquiry Form

The enquiry form allows customers to submit questions about Eco Glow's services and products.

JavaScript is used to check that the required information has been entered.

### Contact Form

The contact form allows visitors to provide their contact details, select a message type and write a message.

The form validates the information and prepares an email using the visitor's default email application.
